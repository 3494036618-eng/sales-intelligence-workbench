# 单工作区自托管 Beta 发布验收清单

本清单是 `0.9.0` Beta 的发布依据。每项必须保留命令结果、截图或业务记录证据；未通过的项目不能在发布文案中宣称已支持。

## 支持边界

- 单工作区、单人使用。
- 本机或受控内网自托管。
- 不提供公网生产 SaaS、多人协作或 SLA。
- 不使用 Mock、固定报告、静态 Provider 结果或旧业务记录冒充真实验收。
